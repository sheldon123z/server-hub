# 网络管理模块 API

提供监听端口、代理状态、连接统计和防火墙规则查询接口。

**路由前缀**: `/api/network`
**相关文件**: `modules/network/routes.py`, `modules/network/services.py`

> 所有端点均需要 admin 权限。

---

## 端点列表

### GET /api/network/ports

列出所有正在监听的 TCP 端口及对应进程信息（通过 `ss` 或 `netstat` 采集）。

**权限**: admin

**请求参数**: 无

**成功响应** `200`:

```json
{
  "ports": [
    {
      "port": 22,
      "address": "0.0.0.0",
      "protocol": "tcp",
      "pid": 1234,
      "process": "sshd",
      "state": "LISTEN"
    },
    {
      "port": 9900,
      "address": "0.0.0.0",
      "protocol": "tcp",
      "pid": 5678,
      "process": "uvicorn",
      "state": "LISTEN"
    }
  ],
  "count": 2
}
```

### GET /api/network/proxy

检查 Clash 代理服务状态和基本配置信息。

**权限**: admin

**请求参数**: 无

**成功响应** `200`:

```json
{
  "clash_running": true,
  "mixed_port": 7890,
  "api_port": 9090,
  "mode": "rule",
  "env_proxy_set": false,
  "http_proxy": ""
}
```

| 字段 | 说明 |
|------|------|
| clash_running | Clash 进程是否运行 |
| mixed_port | HTTP/SOCKS 混合端口 |
| api_port | Clash RESTful API 端口 |
| mode | 当前代理模式（`rule` / `global` / `direct`） |
| env_proxy_set | 系统环境变量是否设置了代理 |
| http_proxy | `HTTP_PROXY` 环境变量值 |

### GET /api/network/connections

获取网络连接统计摘要（TCP/UDP 连接数按状态分组）。

**权限**: admin

**请求参数**: 无

**成功响应** `200`:

```json
{
  "total": 256,
  "by_state": {
    "ESTABLISHED": 48,
    "TIME_WAIT": 12,
    "LISTEN": 32,
    "CLOSE_WAIT": 4
  },
  "tcp": 230,
  "udp": 26
}
```

---

### GET /api/network/firewall

获取当前 iptables 防火墙规则（以纯文本格式返回）。

**权限**: admin

**请求参数**: 无

**成功响应** `200` (Content-Type: text/plain):

```
# Generated by iptables-save
*filter
:INPUT ACCEPT [0:0]
:FORWARD DROP [0:0]
:OUTPUT ACCEPT [0:0]
-A INPUT -p tcp --dport 22 -j ACCEPT
-A INPUT -p tcp --dport 9900 -j ACCEPT
COMMIT
```
